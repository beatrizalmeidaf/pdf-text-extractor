Sem um PDF à mão?

Motor

Nada sai do seu computador: o PDF é lido aqui mesmo, com pdf.js.

Suba a sua com docker compose up. Aceita também DOCX, PPTX, XLSX, HTML e EPUB, e faz OCR de escaneados.

Opções

Ex.: 1-3,5,10-

No modo navegador o arquivo não é enviado a lugar nenhum.

Escolha um PDF para ver a estrutura

Cada bloco aparece destacado na página, no lugar exato onde está.

  • Ordem de leitura correta em documentos de duas ou três colunas
  • Tabelas com e sem bordas viram linhas e colunas (CSV, Excel)
  • Fórmulas com sobrescrito, subscrito e símbolos viram LaTeX
  • Figuras, tabelas e fórmulas também saem como imagem recortada
  • Cabeçalhos, rodapés e números de página são separados do conteúdo

      Como funciona e como usar em código
      

        

          
No navegador

          
O motor de layout roda em JavaScript sobre o pdf.js: agrupa glifos em linhas, detecta colunas com um XY-cut que não confunde coluna de texto com coluna de tabela, reconstrói tabelas pelas réguas ou pelo alinhamento e transforma sobrescritos em LaTeX.

        

        

          
No servidor

          
O mesmo algoritmo roda em Python sobre o PDFium, em paralelo com o Apache Tika, que adiciona metadados, títulos marcados do PDF, OCR com Tesseract e mais de mil formatos (DOCX, PPTX, XLSX, EPUB…).

        

        

          
Em Python

          
pip install pdf-text-api
from pdf_text_api import extract
extract("a.pdf", images=True).to_markdown()

        

        

          
Via API

          
curl -F file=@a.pdf "localhost:8000/v1/extract?format=markdown"
